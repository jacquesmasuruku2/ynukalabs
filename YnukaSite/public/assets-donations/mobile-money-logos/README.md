# Logos Mobile Money (RDC)

Placez ici les fichiers **PNG** (fond transparent recommandé, ~200–320 px de largeur) :

| Fichier       | Opérateur                          |
|---------------|------------------------------------|
| `orange.png`  | Orange Money                       |
| `airtel.png`  | Airtel Money                       |
| `vodacom.png` | Vodacom (M-Pesa)                   |
| `africel.png` | Africel                            |

Les chemins sont utilisés par la page **Onboarding → Donate → Via Mobile Money**.  
Tant que les images sont absentes, l’interface affiche un **pictogramme de secours** avec l’initiale de l’opérateur.
